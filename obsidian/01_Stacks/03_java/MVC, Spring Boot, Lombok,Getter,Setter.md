# 🚀 백엔드 개발자 입문: 핵심 개념 마스터 노트

## 🏗️ Part 1. 설계와 도구 (시스템의 뼈대)

### 1. MVC 패턴 (역할 분담의 규칙)

- **Model**: 데이터와 비즈니스 로직 (요리사).
    
- **View**: 사용자 화면 UI (손님상).
    
- **Controller**: 모델과 뷰를 연결 (웨이터).
    
- **핵심**: 역할을 나누어야 **유지보수**와 **분업**이 쉽다!
    

### 2. Spring Boot (풀옵션 식당)

- 복잡한 설정 없이 버튼 하나로 웹 서버를 실행하는 프레임워크.
    
- 서버 내장, 자동 설정 등으로 **개발 속도**를 획기적으로 높여줌.

## 🛡️ Part 2. 객체 지향의 핵심: 캡슐화 & 무결성

### 1. 캡슐화 (Encapsulation) : "알약처럼 보호하기"

- 데이터(`private`)를 숨기고 메서드(`public`)로만 소통하는 것.
    
- 내부 기계 장치를 가리고 버튼만 내놓은 **자판기**와 같음.
    

### 2. 데이터 무결성 (Data Integrity) : "데이터의 정확성"

- 데이터에 결함이 없고 정확한 상태를 유지하는 것.
    
- 잘못된 값(예: 나이 -500)을 **Setter에서 차단**하여 데이터 신뢰도를 높임.

| **구분** | **캡슐화 (Encapsulation)** | **데이터 무결성 (Integrity)** |
| ------ | ----------------------- | ----------------------- |
| **목표** | 정보 은닉 및 유지보수성           | 데이터의 정확성 및 신뢰도          |
| **도구** | 접근 제어자 (`private`)      | **Setter** 내의 조건문 로직    |
| **비유** | 리모컨 덮개를 씌워둔 것           | 가짜 지폐를 걸러내는 입금기         |

## 💎 Part 3. Getter와 Setter를 쓰는 3가지 결정적 이유
###  Getter / Setter / toString (객체의 매너)

- **Getter**: 데이터를 안전하게 꺼내오는 창구 (읽기 권한).
    
- **Setter**: 데이터를 검사하며 넣는 검문소 (쓰기 권한).
    
- **toString**: 주소값 대신 객체의 '내용물'을 보여주는 **이름표**.

### 변수를 직접 안 쓰고 귀찮게 메서드를 거쳐야 할까요?

1. **값의 무결성 검사 (필터링)**
    
    - 직접 접근하면 잘못된 데이터 입력을 막을 방법이 없지만, **Setter**를 쓰면 `if`문 등으로 검사하여 정상적인 값만 저장할 수 있습니다.
        
    - _예: `setAge(-100)` 호출 시 저장 거부._
        
2. **읽기 전용 / 쓰기 전용 설정 (접근 제어)**
    
    - 변수를 `public`으로 두면 누구나 읽고 쓸 수 있지만, 메서드를 이용하면 권한을 조절할 수 있습니다.
        
    - _Getter만 만들면 **읽기 전용**, Setter만 만들면 **쓰기 전용** 객체가 됨._
        
3. **유지보수의 편의성 (내부 구조 변경 대응)**
    
    - 내부에서 변수 이름을 바꾸거나 구조를 갈아엎어도(예: 성+이름 분리), 외부에서는 똑같은 이름의 **Getter/Setter** 버튼만 누르면 되므로 외부 코드를 수정할 필요가 없습니다.

## 🛠️ Part 4. 실무형 부품 & 데이터 관리

### 1. Lombok (롬복) & 의존성

- **의존성**: 남이 만든 완제품 도구를 빌려 쓰는 규칙 (`build.gradle`).
    
- **Lombok**: 반복되는 Getter/Setter/toString을 자동으로 만들어주는 **자동 도장**.
    

### 2. 참조 (Reference) : "주소가 적힌 쪽지"

- 실물 데이터가 아닌 **메모리 주소**를 들고 있는 방식.
    
- `A = B`는 주소 공유이므로 한쪽을 바꾸면 둘 다 바뀜에 주의!
    

### 3. toString (이름표)

- 객체 출력 시 주소값 대신 **필드 내용**을 한눈에 보여주는 디버깅용 메서드.
