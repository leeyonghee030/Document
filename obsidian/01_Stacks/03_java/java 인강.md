# ☕ Java 기초 핵심 메모

## 1. Java란 무엇인가?

- **정의**: 웹, 모바일 앱, 서버 프로그램 등 다양한 환경에서 실행되는 객체지향 프로그래밍 언어.
    
- **특징**: "한 번 작성하면 어디서든 실행된다(Write Once, Run Anywhere)"는 철학을 가지고 있어 운영체제(Windows, Mac, Linux)에 상관없이 돌아갑니다.
    

## 2. Java 프로그램의 기본 단위: 클래스(Class)

- **정의**: 객체를 만들기 위한 **설계도**이자 틀.
    
- **구성 요소**:
    
    - **필드(Field)**: 데이터 혹은 상태 (예: 자동차의 색상, 현재 속도).
        
    - **메서드(Method)**: 기능 혹은 동작 (예: 가속하기, 브레이크 밟기).
        

## 3. 객체(Object)와 인스턴스(Instance)

- **객체**: 클래스라는 설계도로 만든 **실제 물건**.
    
- **인스턴스**: 특정 클래스로부터 만들어진 객체를 부르는 말 (예: "이 '소나타'는 `Car` 클래스의 인스턴스다").
    
- **메모리**: 객체는 컴퓨터의 **Heap(힙) 메모리**라는 공간에 실제로 자리를 잡고 살아갑니다.
    

## 4. 엄격한 자료형(Strongly Typed)

자바는 변수를 만들 때 어떤 종류의 데이터를 담을지 미리 선언해야 하며, 이를 어기면 컴파일 에러가 납니다.

- **기본 자료형(Primitive)**: `int`(정수), `double`(실수), `boolean`(참/거짓), `char`(문자 하나).
    
- **참조 자료형(Reference)**: `String`(문자열), `Scanner`, 클래스로 만든 객체 등. (실제 데이터가 아닌 **주소**를 저장함).
    

## 5. JDK: 자바 개발의 필수 세트

Java 프로그램을 만들고 실행하려면 반드시 **JDK**가 필요합니다.

- **JDK (Java Development Kit)**: 개발 도구 모음.
    
    - **컴파일러(javac)**: 우리가 쓴 글자를 기계용 언어로 번역.
        
    - **JRE (Java Runtime Environment)**: 자바 실행 환경 (JVM이 포함됨).
        
    - **라이브러리**: 미리 만들어진 유용한 도구들.
        

## 6. Java 소스가 실행되는 과정 (매우 중요!)

1. **코드 작성**: `.java` 파일 생성 (사람이 읽는 코드).
    
2. **컴파일**: `javac` 도구가 `.java`를 **바이트코드(`.class`)**로 번역.
    
3. **실행**: **JVM**이 바이트코드를 읽어서 컴퓨터가 이해하는 0과 1로 바꿔 실행.
    

## 7. Java 플랫폼: JVM과 API

- **JVM (Java Virtual Machine)**: 자바 바이트코드를 실행하는 **가상 컴퓨터**. OS와 프로그램 사이에서 통역사 역할을 하여, 어떤 컴퓨터에서든 자바가 돌아가게 해줍니다.
    
- **Java API**: 자바 언어와 함께 제공되는 **방대한 기능 꾸러미** (문자열 조작, 시간 계산, 데이터 보관 등).
    

## 8. 프로그램의 입구: main() 메서드

자바 프로그램은 무조건 `public static void main(String[] args)`를 찾아서 거기서부터 시작합니다.

- **public**: 누구나(JVM 포함) 접근 가능해야 함.
    
- **static**: 객체를 만들기 전에도 이 시작 버튼을 누를 수 있어야 함.
    
- **void**: 이 메서드가 끝나고 나면 결과물을 따로 돌려주지 않음.
    
- **String[] args**: 프로그램을 실행할 때 외부에서 던져주는 데이터(옵션)를 담는 바구니.

## 📌 핵심 키워드 최종 정리 (비유)

| **개념**       | **비유**     | **한 줄 핵심**               |
| ------------ | ---------- | ------------------------ |
| **클래스**      | **설계도**    | 객체를 찍어내기 위한 틀            |
| **객체**       | **실제 물건**  | 메모리에 구현된 실물              |
| **JDK**      | **연장 통**   | 자바 개발에 필요한 모든 도구         |
| **컴파일**      | **번역**     | 자바 언어를 기계용 코드로 바꾸는 일     |
| **바이트코드**    | **중간 번역본** | JVM만 읽을 수 있는 `.class` 파일 |
| **JVM**      | **실행기**    | 프로그램을 실제로 돌려주는 가상 머신     |
| **Java API** | **사전/도구함** | 자바가 기본으로 주는 유용한 기능들      |
| **main()**   | **시작 버튼**  | 프로그램이 첫 발을 떼는 입구         |
