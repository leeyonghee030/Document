## 1. 자바의 3대 글자 규칙 (Case)

컴퓨터는 공백을 인식하지 못해서 단어를 붙여 써야 합니다. 이때 읽기 편하게 만드는 약속입니다.

- **카멜 케이스 (camelCase)**: **변수, 메소드**에 사용. 첫 글자는 소문자, 다음 단어 첫 글자만 대문자. (낙타 등 모양)
    - _예: `userName`, `loginUserPwCheck()`_
- **파스칼 케이스 (PascalCase)**: **클래스** 이름에 사용. 첫 글자부터 대문자.
    - _예: `ResponseDto`, `UserController`_
- **스네이크 케이스 (SNAKE_CASE)**: **상수(변하지 않는 값)**에 사용. 모두 대문자 + 언더바(`_`).
    - _예: `MAX_LOGIN_COUNT`_

## 2. 메소드(Method) 이름: "동사"로 시작 (동작)

메소드는 어떤 기능을 실행하는 **'행동'**이므로 동사를 먼저 씁니다.

### 📥 생성 및 저장 (가장 많이 헷갈리는 3대장)

- **`save`**: 데이터를 만들어서 **DB나 리스트에 넣는 것**까지 포함할 때 (**실무 권장**)
    - _예: `saveTodo()` (할 일을 작성해서 저장까지 완료)_
- **`create`**: 새로운 객체를 **조립해서 리턴**만 할 때 (무에서 유를 창조)
    - _예: `createToken()` (인증 토큰을 새로 만들어내기)_
- **`add`**: 이미 있는 **바구니(List)에 항목을 하나 쏙 넣는** 단순 동작일 때
    - _예: `addComment()` (댓글 목록에 하나 추가)_

### 📤 조회 및 삭제

- **`get`**: 데이터를 가져올 때 (가장 기본) -> `getName()`
- **`find`**: DB 등에서 특정 조건으로 찾아올 때 -> `findTodoById()`
- **`update` / `modify`**: 수정할 때 -> `updateStatus()`
- **`delete` / `remove`**: 삭제할 때 -> `deleteById()`

## 3. `is` 계열 이름: "질문과 답변" (Boolean)

결과값이 **Yes(true) / No(false)**인 경우에만 사용하며, 질문을 던지는 형태입니다.

- **`is` + 상태**: "~인가?" (현재 상태 확인)
    - _예: `isEmpty()` (비었니?), `isValid()` (유효하니?)_
- **`has` + 명사**: "~을 가지고 있는가?" (소유 여부)
    - _예: `hasRole()` (권한이 있니?), `hasToken()` (토큰이 있니?)_
- **`can` + 동사**: "~ 할 수 있는가?" (가능 여부)
    - _예: `canMove()` (움직일 수 있니?), `canDelete()` (삭제 가능한가?)_
- **`exists`**: "존재하는가?" (주로 DB에 데이터가 있는지 확인)
    - _예: `existsByEmail()` (이 이메일로 가입된 사람이 있니?)_

---

## 4. 변수(Variable) 이름: "명사"로 시작 (데이터)

변수는 데이터를 담는 **'그릇'**이므로 상태를 나타내는 명사를 사용합니다.

- **단수/복수**: 한 개면 단수, 여러 개면 뒤에 `s`나 `List`를 붙입니다.
    - _예: `user` (한 명) / `users`, `userList` (여러 명)_
- **구체적으로**: `data`, `val` 같은 애매한 이름보다 정체를 확실히 밝힙니다.
    - _예: `temp` (X) → `targetDate` (O)_

## 💡 초보자를 위한 네이밍 "국룰" 정리

1. **약어(줄임말) 쓰지 않기**: `uNm`보다는 `userName`이 훨씬 좋습니다. 나중에 다시 봐도 이해되는 게 최고입니다.
2. **클래스 내부 이름 중복 피하기**: `User` 클래스 안의 변수는 `userName`보다 그냥 `name`이 좋습니다. (이미 User 안에 있으니까요!)
3. **동사 + 목적어 순서**: 영문법처럼 지으면 자연스럽습니다.
    - _예: `checkPassword()` (비밀번호를 체크하다)_
